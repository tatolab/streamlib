# strict-port-families

> **The five port families**, decided by the owner on 2026-11-03 (§Processor model &
> scheduling, `ARCHITECTURE.md:1303-1335` and `:1440`, and
> `docs/decisions/strict-port-families.md`). This change rides the transport
> `zero-copy-data-plane` shipped (#3168, #3174, #3191): the user-header descriptor, borrowed
> reads, loaned writes, the per-link quota and the GPU pool claim table. It settles the OPEN on
> how names and `requires=` are spelled (`ARCHITECTURE.md:1334-1335`). The owner chose the spelling on 2026-11-04: names are
> strings, stated literally or read from config, with `requires=` as a subset check at connect.

Today a port carries bytes and nothing says what they are. A port is a decorated method,
`@node.output() def video(self) -> VideoFrame: ...`, whose return annotation only humans and
pyright read (`tatolab/stream/_node_declaration.py:355-456`). `connect` checks only that both
ports exist (`operations_runtime.rs:312`, `apply_a_link`). A mismatched link surfaces as a decode failure in
the consumer. Writers build msgpack maps by hand or through `MsgpackCast`, and nothing checks a
key.

**After this change:**
- **Every port is a class attribute with a family:** `video = Output(Image)`,
  `audio = Input(Channels, delivery="ordered", requires=("left",))`. Pyright infers what a
  read returns, and a mistyped port fails at import.
- **`connect` refuses a family mismatch before a frame flows**, naming both ports and both
  families, and refuses a `requires=` name the output does not declare.
- **Conversion is a node someone places:** `ImageToArray`, `ArrayToImage`, `ChannelsToArray`,
  `ArrayToChannels`, `ChannelsToRecords` and `RecordsToChannels` join the existing codecs (Image ↔
  Packets through h264/h265, Channels ↔ Packets through opus).
- **Records takes a plain dict.** The runtime encodes it, and msgpack leaves user code.
- **The whole tree moves in this change:** every built-in, every cast type, `tatolab-stream`,
  the scaffold and each module in `packages/`. Records carries a node not yet converted while
  the migration runs.

**Scale gate — this skill plus the existing ADR** (`docs/decisions/strict-port-families.md`).
No new ADR.

## Current state (recon, 2026-11-06, `main` `6798716`)

- **Python ports** are `node.input(name, description, delivery_profile, borrow_quota,
  audio_window)` and `node.output(name, description, catalog)` decorators on methods
  (`_node_declaration.py:355`, `:433`), marked by `_INPUT_PORT_MARKER_ATTRIBUTE` and
  `_OUTPUT_PORT_MARKER_ATTRIBUTE` (`:256-257`). There are 49 of them in `packages/`. By annotation they are `VideoFrame` (22),
  `bytes` (5), and unannotated (22: encoded video and audio, events, `data`, `tracks`, `audio`).
- **Rust ports** are declared by `#[streamlib::sdk::processor(...)]` (`sdk/streamlib-macros`).
  The engine's Rust nodes are `RelayTrackSource` (`streamlib-media-builtins/src/relay_track_source.rs:102`),
  the owned-device codec nodes (`streamlib-owned-device-video-codec-nodes`) and the test fixtures.
- **The descriptor** is `PortDescriptor { name, description, required, delivery_profile,
  borrow_quota, audio_window, catalog_entry }` (`sdk/streamlib-processor-schema/src/descriptors.rs:27`).
  It has no family and no names.
- **The payload descriptor** has two kinds, `Bytes = 0` and `GpuPoolSlotFrame = 1`
  (`streamlib-ipc-types/src/lib.rs:623-626`). A read returns `PortPayloadBorrow`; a pooled GPU
  frame's `VideoFrame` record still names `surface_id`, and `write(..., pooled_gpu_frame=)` or a
  frame the node acquired attaches the descriptor (`_node_context_protocols.py`, `write`).
- **Cast types**: `VideoFrame` (`video_frame.py:189`) and `AudioBlock` (`audio_block.py:41`),
  both `MsgpackCast`, mirrored in Rust by `streamlib-media-builtins/src/{video_frame,audio_block}.rs`.
  `_built_in_nodes.py` is generated by `cargo xtask generate-built-in-node-classes`.
- **`audio_window`** is the Channels input contract under its old name: rate, dtype, window
  size, hop and optional channel count (`AudioWindowContract`).

## ADDED

- **ADDED (§Processor model & scheduling, DECIDED; settles the spelling OPEN):** A port is a
  class attribute, `Input(family, …)` or `Output(family, …)`. The attribute's name is the port's
  name, and there is no `name=` override. The family is one of `Image`, `Array`, `Channels`,
  `Packets` or `Records`, imported from `tatolab.stream`. Inputs take `delivery=` ("newest" or
  "ordered", required), `borrow_quota=` (from `zero-copy-data-plane`), `requires=` and
  `description=`. Outputs take `names=`, the family's own keys below, `catalog=` and
  `description=`. [strict-port-families]
- **ADDED (same section, DECIDED):** Names are strings. An output states them as a literal tuple
  (`names=("rpm", "torque")`) or reads them from its node's config
  (`names=from_config("channel_names")`), which connect resolves once the node's config is
  known. `requires=` is a tuple of strings, and `connect` refuses unless it is a subset of the
  output's resolved names, naming each missing one. An output that states no names accepts no
  `requires=`. Rejected: names fixed on the class only, which leaves an output whose channels come
  from config unable to be required against; and a typed spec per name, which duplicates the
  runtime descriptor (owner, 2026-11-04). Names live per family: channel names (Channels), attribute names (Array) and
  record keys (Records). Image and Packets have no names; Packets states `codec=` instead, which
  an input may require (`requires_codec=("h264",)`). A `from_config` name list is resolved again
  on each live config update of its node, and an update that drops a name a wired link
  requires is refused naming the link, so a link that passed `connect` stays valid.
  *(Assumed; correct it if a live update should instead unwire the link.)* [strict-port-families]
- **[NEEDS DECISION] (same entry): what an Image input states about formats.** An output
  declares `formats=`, but nothing above stops an `rgba16f` output reaching an input that only
  reads `rgba8` (the compositor's landing copy needs `rgba8_unorm`), so the frame fails after
  the link is made. Options: (a) an Image input may state `formats=` too, and `connect` refuses
  unless the two sets overlap, naming both; (b) formats stay output-only and the reader refuses
  per frame, counted as a drop. Recommended: (a), the same check `requires=` already makes.
- **[NEEDS DECISION] (same entry): do a Records output's names promise every key in every
  write?** Options: (a) yes, `write` refuses a dict missing a declared name, naming it, so
  `requires=` means the key is always there; (b) no, declared names say which keys may appear,
  and a reader handles absence. Recommended: (a). It is one set check per write on a family
  already capped at 64 KiB, and without it `requires=` promises nothing on Records.
- **ADDED (same section, DECIDED):** Each family's keys and what a read returns:
  - `Image`: `Output(Image, formats=("rgba8",))`. A read returns `ImageFrame`, the borrowed GPU
    surface with `__dlpack__`, `.cpu()`, `.writable()`, size, format and colour.
  - `Array`: `Output(Array, names=(…), residency="gpu" | "cpu")`. A read returns `ArrayFrame`,
    a mapping of name to a borrowed tensor (DLPack), each with its dtype and shape. An
    attribute that did not change passes by reference.
  - `Channels`: `Output(Channels, names=(…) | from_config(…), rate=… | from_config(…),
    dtype="f32" | "f64")`. A read returns `ChannelsBlock`, planar `[channel][sample]` with
    `start_sample` and the rate. The input's `window=` takes today's `AudioWindowContract`.
  - `Packets`: `Output(Packets, codec="h264")`. A read returns `PacketsUnit`, borrowed
    bytes with `pts`, `starts_group` (the keyframe) and `codec`.
  - `Records`: `Output(Records, names=(…))`. `write(port, {...})` takes a plain dict of at most
    64 KiB, encoded, and a read returns a `dict`. The catalog marks a Records port unchecked.
  [strict-port-families]
- **ADDED (§Processor model, DECIDED):** `PortDescriptor` gains `family`, `names`,
  `names_from_config_key`, `requires`, `codec`, `requires_codec`, `rate`, `formats` and
  `residency`. `DataChannelPayloadDescriptor` gains one kind per family, each with its
  `#[repr(C)]` body and layout test, replacing `Bytes` for every family but Packets and Records.
  An Image frame's body starts with today's `GpuPoolSlotFrame` body (40 bytes); the
  `VideoFrame` msgpack record and `pooled_gpu_frame=` go. [strict-port-families]
- **ADDED (same entry, DECIDED):** An Image frame's body is the slot reference (40 bytes),
  then `width: u32`, `height: u32`, `format: u32` and the H.273 colour four-tuple (primaries,
  transfer, matrix, range) as four `u8` codes, 56 bytes in all. `fps`, `content_light` and
  `mastering_display`, which `VideoFrame` carries today (`video_frame.py:205-213`), move to
  the port's catalog entry as stream-level facts, updated through `set_catalog_entry`. Every
  Image read is a fixed layout with no decode. Per-frame dynamic HDR (HDR10+, Dolby Vision)
  is a later descriptor kind, whose metadata rides the sample's payload bytes, which an Image
  sample leaves empty; today's kind is unchanged by it. Owner, 2026-11-06.
  Rejected: per-frame metadata as an encoded record in the payload — every Image read decodes
  (owner, 2026-11-06).
- **ADDED (§Processor model, DECIDED):** `connect` compares the families by equality, then
  names, then codec, and refuses on the first mismatch with an error naming both endpoints,
  both families, and what to place between them (the conversion nodes below). The live graph's
  `apply_a_link` runs the check before the channel exists. [strict-port-families]
- **ADDED (§Processor model, conversion nodes, DECIDED):** Six built-in Rust nodes, each one
  input and one output:
  - `ImageToArray`: zero-copy where the layouts match (a linear `rgba8`/`rgba16f`/`r8` slot
    borrowed as one `[h, w, c]` attribute), and one GPU copy where they do not, stated in the
    node's description.
  - `ArrayToImage`: the inverse, from a named `[h, w, c]` attribute.
  - `ChannelsToArray` and `ArrayToChannels`: a `[channels, samples]` attribute.
  - `ChannelsToRecords` and `RecordsToChannels`: latest-value control, for named values.
  Encoding and decoding stay the codec modules' job. [strict-port-families]

  `ctx.outputs.write`/`loan` are typed per family through the port attribute (`ctx.inputs.read(self.video)`

  `ChannelsBlock`.
- **MODIFIED (`sdk/streamlib-macros`):** `#[processor]` port syntax gains the family and its
  keys, and the macro refuses a port without a family.
- **MODIFIED (each module in `packages/`):** every port is redeclared by family. Camera,
  testpattern, rive, compositor, virtualcamera and browser video become `Image`. Microphone,
  speaker and browser audio become `Channels`. h264, h265, opus and webrtc tracks become
  `Packets`. Browser events and data, and rive `data`, become `Records`.
- **MODIFIED (`RelayTrackSource`):** its config gains a required `family` (with `codec` for
  Packets, and `names` for Channels, Array and Records, read through `from_config`), because a
  relay track's family is the publisher's and connect needs it before the catalog arrives. When
  the catalog arrives and disagrees with the configured family, codec or names, the source
  fails naming the track and both values, never publishing a frame of the wrong shape.
  *(Assumed.)*
- **MODIFIED (scaffold, `runtime/tatolab-cli`):** `streamlib new` writes class-attribute ports.

## Proof

- Connect: one test per refusal (family, names, codec), each naming both endpoints. A
  `from_config` names output resolves and passes `requires=`.
- Pyright: a fixture node whose `ctx.inputs.read(self.video)` is used as a `ChannelsBlock` fails
  type checking. A port declared without a family fails at import.
- Layout regression tests for every family's descriptor body.
- `ImageToArray`: the borrowed tensor's data pointer equals the slot's mapping when the layouts
  match (zero copies), on lavapipe and the rig.
- Each converted module's existing tests pass under its new ports. The conformance gate and
  `generate-built-in-node-classes --check` pass.

## Tickets (expected), expand, migrate, contract

1. **Expand (engine and SDK):** families on `PortDescriptor` and the macro, the connect checks,
   `Input`/`Output` and the read types in `tatolab-stream`, and the descriptor kinds. A
   decorator port reads as an unchecked `Records` port, and `connect` skips the family, names
   and codec checks on a link with one at either end, so a migrated camera still links to an unmigrated
   consumer while tickets 3 and 4 run. Ticket 5 deletes that skip with the decorators.
2. **Conversion nodes:** the six built-ins, with `ImageToArray`'s zero-copy proof.
3. **Migrate the engine tree:** `RelayTrackSource`, the codec nodes, the test fixtures, the
   scaffold, and `VideoFrame`/`AudioBlock` to `ImageFrame`/`ChannelsBlock`.
4. **Migrate `packages/`:** every module, one commit each.
5. **Contract:** delete the decorators, `MsgpackCast`, `msgpack.py`, `video_frame.py`,
   `audio_block.py` and the decorator-port skip in `connect`, and run the removal gate.
