# Docs index

Where each kind of document lives. Code is the authority on what is; `docs/plan/` is the authority
on what we agreed.

- [`plan/`](plan/) — the architecture plan, the glossary, the operating model, and change
  proposals. The single source of architectural decisions.
- [`decisions/`](decisions/) — ADRs: why a shape was chosen over the alternatives.
- [`working-agreements.md`](working-agreements.md) — owner rulings on how sessions work, and
  practical lessons from the repo, the rig and CI that no other file records.
- [`learnings/`](learnings/) — surprising driver, library and spec behaviour: symptom, cause, fix.
- [`architecture/`](architecture/) — current shipped state of specific subsystems.
- [`research/`](research/) — dated memos answering one question from primary sources.
- [`testing-hardware.md`](testing-hardware.md) — the hardware-integration test tier.
- [`rig-profile.example.md`](rig-profile.example.md) — template for a machine's local rig profile.
- [`logging.md`](logging.md) and [`logging-schema.md`](logging-schema.md) — how to log, and the
  durable JSONL log contract.
- [`assets/`](assets/) — the README demo's terminal recording script.
- [`license/`](license/) — licence texts and notes. Never edit without the owner's approval.
