Streams, nodes, one runtime per machine — what the pivot commits to

A stream is what you write and run today as an app. One runtime per machine runs many streams from different people or teams, behind that machine's single Zenoh router, and decides what leaves the machine. Every exposed port is a URL, in whatever form the consumer wants. Networking and the GPU stop being wired into every app. This page is the whole of it: what is decided in your words, what is open with the review's direction, and what it will take.

Decided: 16 plan entries, all traceable to your five sentences and your rulings on 30 September. Open: 15 entries, each carrying the review's direction marked as such, never as a decision. Vocabulary: settled in the glossary — stream, node, name, port, link, address, exposed port, form, graph, runtime, machine, relay — with engine-only words kept behind them. One assumption you may reverse: the per-machine program is called the runtime, not the host.

1 · What changes for a person using streamlib

Almost nothing in the calls, and a lot in what they are called on. The class you write is a @node, a stream is a function decorated @stream (as many per file or package as you like), and it receives a Stream builder rather than the runtime — because a stream is being built, not a runtime modified.

# stream.py — one or more @stream functions; the function's name is the stream's
from nodes.inverting_effect import InvertingEffect
from tatolab.stream import CameraSource, DisplayWindow, Stream, stream

@stream
def demo(stream: Stream) -> None:
    """Camera, inverted, in a window."""
    camera = stream.add(CameraSource, name="camera")
    invert = stream.add(InvertingEffect, name="invert")
    window = stream.add(DisplayWindow, name="window", config={"title": "Demo"})
    stream.connect(camera.output("video"), invert.input("video_from_upstream"))
    stream.connect(invert.output("video_to_downstream"), window.input("video"))
    stream.expose(invert.output("video_to_downstream"))

# nodes/inverting_effect.py
from tatolab.stream import NodeContextLimitedAccess, VideoFrame, input, node, output

@node
class InvertingEffect:
    @input(delivery_profile="newest")
    def video_from_upstream(self): ...
    @output()
    def video_to_downstream(self): ...
    def process(self, ctx: NodeContextLimitedAccess): ...

Then, on the same machine, with nothing else installed:

$ tatolab run demo                       # loads into this machine's runtime, or starts one here
$ tatolab streams
$ curl -N http://127.0.0.1:<port>/demo/invert/video_to_downstream/ndjson | jq .
$ ffplay  http://127.0.0.1:<port>/demo/invert/video_to_downstream/ts
$ tatolab expose demo/invert/video_to_downstream     # lets it leave the machine, under the stream map
Stays exactly as it is

7 · Security — what is true today, and what the map needs

Live today, and not waiting on the pivot: every runtime listens on all interfaces with multicast on; link requests from any peer are applied unchecked; every output port is offered; the MCP server binds 0.0.0.0:9000 with authentication off and no Host or Origin check. The mesh link is plaintext with no integrity tag. Runtime names are self-declared: anyone on the network can impersonate one, squat one, or remove any link.

  • A link-layer check alone is bypassable. Data rides a plain Zenoh key per port; anyone with reach can announce a reader and subscribe to streamlib/**. So the map compiles into Zenoh's own access control (static; changing it restarts the session) and engine checks at the three existing sites; per-stream encryption keys are the only permission a router cannot bypass.
  • Peer identity is mTLS with a per-machine certificate where Tailscale is absent; on a tailnet, Tailscale's identity and WireGuard already cover it. Per-person or per-agent grants on relayed traffic must be signed tokens the runtime checks, because a router sees only its neighbour's certificate.
  • End-to-end through a relay means the runtime encrypts payloads itself (Zenoh's TLS is hop by hop); sequence numbers and stamps stay readable but tamper-proof, so drop counting still works. It removes every server-side form; stock ffmpeg and curl then work only through TLS ending on the machine. Encoded video costs little to encrypt; raw 1080p would swamp a small ARM board.
  • Hardening that ships now, without a decision: Host and Origin checks on the control server and the tap WebSocket; refuse a remote disconnect of a link the requester did not create; gossip off when multicast is off; cap Zenoh's 1 GiB default message size.

8 · Packaging, and "never reinstall the runtime"

Verified by building it: maturin ships tatolab.runtime._native as a PEP 420 namespace portion beside a pure tatolab-stream, in wheels and editable installs alike. No custom module system.

Option for the build handshakeResult
Every stream venv pins the exact runtimeInverts the constraint: every runtime upgrade reinstalls every stream, and puts the heaviest artifact in every venv on low-power devices.
A versioned wire protocolThe retired integer on a bigger surface; the iceoryx2 memory layout is a third-party contract nobody can version.
A stable C ABI between runtime and interpreterThe deleted plugin ABI, rejected already.
The runtime lends its native portion to the stream's PythonThe interpreter runs the stream venv's Python with the runtime's tatolab/runtime first on PYTHONPATH. The handshake passes by construction, and still catches a venv whose own stale runtime shadowed the lend. "Never reinstall" holds within an authoring API level the runtime declares.

Accelerators optional is a runtime property, not a package: an extra cannot change the runtime's native module, and a second engine-linking distribution reverses two decided entries. The smallest shape is the one you preferred on 26 September: one artifact, a bundled software Vulkan last in device selection, absent tiers refused by name.

10 · Risks worth carrying

  • A native crash in a built-in ends every stream on the machine — the price of in-process media, unchanged in kind. Question 1 decides whether that is acceptable.
  • The lent-portion trick fails if a stream's venv pins its own runtime package in a way that shadows the lend. Test that first.
  • With no map, two runtimes on a LAN exchange nothing until expose runs — a regression from today's zero-setup mesh, if sentence 3 is read literally.
  • A relay-role runtime sees plaintext unless the map carries content keys. One GPU context means one stream's pool growth can starve another until resources are decided.
  • The word "node" flips meaning (it was a live runtime); six skills, the registry and the memories re-spell it once.
  • All macOS permission prompts are credited to the first terminal that started the runtime, until the product app starts it.

11 · Decisions only you can make

  1. Must a native crash in one stream leave the other streams running? Answered 30 Sep: no — one engine for every stream, re-loaded from saved graphs after a fault.
  2. With no stream map, what may reach a stream from another machine? Answered 30 Sep: nothing until expose; then any peer that can reach the machine, narrowed by a pushed map when there is one.
  3. When the terminal that started a foreground runtime closes, do joined streams end with it? Proposed: yes.
  4. Does a stream's venv install only tatolab-stream, with the runtime lending tatolab.runtime?
  5. Is the address <machine>/<stream>/<node>/<port>, the stream replacing today's runtime name? Answered 30 Sep: yes, with collision rules recorded as the direction.
  6. Is a graph only ever written out by the engine, or may people write one by hand? Answered 30 Sep: emitted only; the stream's function wins over live edits on the next start. Environments are provisioned by the standard toolchain (uv, pyproject.toml, a package index, git), never by machinery of ours.
  7. Is the MoQ server permanently external? And are ndjson, ts/fmp4 and WHEP the first forms?
  8. Is end-to-end encryption through a public relay a launch requirement?
  9. "runtime" or "host" for the per-machine program? The branch says runtime; one substitution reverses it.
